# 푹신푹신 (poogsin)

지하철 좌석 점유자의 **하차 정보를 나누는 리워드 기반 웹앱** — MVP.
앉은 사람이 하차역을 남기면(공급) 포인트를 받고, 선 사람은 포인트/광고로 빈자리 힌트를 얻습니다(수요).

## 지금 동작하는 것 (1차 완성)

전체 흐름이 **임시(목업) 데이터**로 실제 동작합니다:

1. **홈** — 노선도 + 검색창 + 내 주변 역
2. **역 클릭** (지도의 '갈산' 역) → 출발/경유/도착 팝오버 + 도착정보 시트
3. **출발 선택** → 경로 입력창
4. **도착까지 선택** → 시간·정렬 탭 + 경로 요약 시트
5. **상세 경로** — 실시간 환승/빠른 하차 문/대기시간
6. **칸 선택** → **좌석 도식**
   - 빈 좌석 탭 → 하차역 입력 → **+15P 적립 (공급)**
   - `하차예정지 확인하기` → **1P 차감 → 점유 좌석에 "N역" 배지 공개 (수요)**
7. **포인트 지갑** — 적립/차감 내역

## 아직 "가짜"인 것 → 다음 단계

지금은 지도·도착정보·경로가 **고정된 예시 데이터**입니다. 실제로 만들려면:

| 할 일 | 필요한 것 | 비고 |
|---|---|---|
| 실시간 도착·열차위치 | 서울열린데이터광장 **API 키** | 무료. 서울 지역 |
| 경로검색·노선도 | **ODsay API 키** | 무료 쿼터 있음. 전국 |
| 회원가입·로그인·좌석 실시간 공유·포인트 저장 | **Supabase** 프로젝트 | 무료로 시작 가능 |

> 이 API 키들은 **사장님 명의로 각 사이트에 가입해서 발급**받아야 합니다.
> 발급받으면 제가 코드에 연결해 드립니다. (키는 절대 코드에 그대로 넣지 않고 `.env` 파일로 안전하게 관리합니다.)

## 폴더 구조 (간단 지도)

```
poogsin/
├─ src/
│  ├─ app/
│  │  ├─ layout.tsx      … 앱 전체 껍데기(제목·언어 설정)
│  │  ├─ page.tsx        … 첫 페이지 (앱을 불러옴)
│  │  └─ globals.css     … 전체 디자인(색·글꼴·화면 스타일)
│  ├─ components/
│  │  ├─ PoogsinApp.tsx  … 핵심! 모든 화면과 화면 전환 로직
│  │  └─ MapView.tsx     … 지도(개략도) — 나중에 실제 지도로 교체
│  └─ lib/
│     └─ data.ts         … 임시 데이터 (나중에 실제 API로 교체)
└─ README.md             … 이 문서
```

**고칠 게 있으면 대부분 `PoogsinApp.tsx`와 `globals.css`만 보면 됩니다.**

## 기술 스택

- **Next.js 16** (React 19) + **TypeScript** — 웹앱 뼈대
- 순수 **CSS**(디자인 토큰) — 라이트/다크 모드 자동 지원
- 예정: **Supabase**(백엔드·DB·로그인·실시간), **Vercel**(배포)
